# 陀螺仪转动角度（theta）功能说明

## 1. 功能概述

在「实验数据」面板中新增「陀螺仪 HWT906P」子面板，实时显示 HWT906P 的三方向角度，
并用四元数方法计算平面绕轴 L 转动的角度 theta：

| 显示项 | 含义 |
| --- | --- |
| 初始 Yaw1 / Pitch1 / Roll1 | 点「记录」时锁定的初始姿态 |
| 当前 Yaw2 / Pitch2 / Roll2 | 陀螺仪实时姿态 |
| 转动角 theta | 相对初始姿态的转动角，单位 °，范围 0~180 |
| 转轴 L | 相对转动的单位转轴 (x, y, z) |
| 端口 / 状态 / 速率 / 温度 | 连接状态与数据质量 |

按钮：

* **记录**：锁定当前姿态为初始姿态 (Yaw1, Pitch1, Roll1)，theta 从 0 开始计数。
* **清零**：丢弃基准，theta 回到未测量状态（显示 `--`）。
* **连接 / 断开**：打开或释放陀螺仪串口（默认 115200 bps）。

## 2. theta 的计算方法（四元数）

设 q1、q2 分别为记录时与当前的姿态四元数（w, x, y, z）：

```
q_delta = q2 ⊗ q1⁻¹                    # 相对转动四元数
theta   = 2·atan2(‖v‖, |w|)            # v = q_delta 的 (x, y, z) 部分
L       = v / ‖v‖                      # 转动轴（单位向量）
```

实现见 `services/rotation_math.py` 的 `relative_rotation()`。

几个刻意的设计：

1. **用四元数差分而不是欧拉角直接相减**：欧拉角在 ±180° 处会跳变。
   例如从 179° 转到 -179°，欧拉角相减得到 358°，而四元数差分得到正确的 2°。
2. **用 atan2(‖v‖, |w|) 而不是 acos(w)**：theta 接近 0 时数值更稳定。
3. **取 |w|**：四元数 q 与 -q 表示同一姿态，取绝对值消除这种双重覆盖。
4. **四元数缺失时用欧拉角兜底**：部分固件不开 0x59 四元数包，
   此时用 `euler_to_quaternion(Yaw, Pitch, Roll)`（ZYX 顺序）换算，逻辑不变。

## 3. 依赖安装

```bash
pip install pyserial numpy
```

* `pyserial`：串口通信（HWT906P SDK 依赖）。
* `numpy`：SDK 内部静态检测与数组运算。
* 官方 SDK 已内置在仓库 `hwt906p/` 目录，无需另外拉取。

## 4. 使用步骤

1. 用 USB 转串口连接 HWT906P，在设备管理器确认串口号（如 COM3）。
2. 打开软件，在「陀螺仪 HWT906P」面板里选择「端口」，「波特率」保持默认的 **自动**，点「连接」。
   面板会显示「连接中…」，连上后变为「● 已连接 921600」，并显示数据速率。
   - 自动识别会依次尝试 921600 / 115200 / 460800 / 9600（本机 HWT906P 实测为 **921600**，
     与 `陀螺仪工具软件.py` 的默认值一致）。识别不到会直接把尝试过的波特率写在提示里。
   - 也可以在面板上手动指定波特率。若报"已打开但没有收到数据帧"，
     通常是波特率不对，或串口被 WitMotion 上位机、陀螺仪工具软件占用。
3. 将平面置于初始位置，点「记录」，此时 theta = 0.00，初始角度被锁定。
4. 让平面绕轴 L 转动，theta 实时显示转动角度，转轴 L 显示实际转动轴。
5. 换一个初始位置重新测量时，点「记录」覆盖基准；点「清零」放弃本次测量。

> 说明：本机 HWT906P 默认只输出加速度/角速度/角度包，**没有输出四元数包**（读回的
> quat 恒为 1,0,0,0）。此时程序会自动用 `euler_to_quaternion(Yaw, Pitch, Roll)` 兜底换算，
> theta 的计算方式与精度不变；若希望设备直接输出四元数，可用 SDK 的
> `write_register(0x02, ...)` + `save_config()` 打开对应输出位后再重新连接。

## 6. 代码分层与线程模型

```
services/rotation_math.py   纯数学，无 IO、无第三方依赖，可单独测试
services/gyro_service.py    设备生命周期 + 后台线程 + 线程安全快照 + 记录/清零状态机
views/gyro_panel.py         只做布局与刷新（after 轮询），不含设备逻辑
utils/resources.py          资源路径解析（兼容 PyInstaller）
sWATGUI.py                  组装根节点：把面板挂到 fr_configpara 的空白区域
```

线程模型：

* 打开/关闭串口、枚举串口、读取寄存器等耗时操作全部在子线程执行，
  `start()` / `stop()` 立即返回，主线程不会卡顿（界面不会假死）。
* 数据回调运行在 SDK 读线程：只做 O(1) 计算（theta）并写入
  `queue.Queue(maxsize=1)`，绝不直接操作 tkinter。
* UI 用 `root.after(50, ...)` 轮询服务快照刷新界面，跨线程零共享控件。

## 7. 打包（PyInstaller）注意事项

资源读取统一走 `utils/resources.py` 的 `resource_path()`，打包后自动指向
`sys._MEIPASS`。打包时需要把这些资源一起收集：

```bash
pyinstaller -w -n sWAT main.py --add-data "no frame.png;." --add-data "DMM1600_1200交大校准完成后的数据.txt;."
```

注意：`hwt906p`、`services`、`views`、`utils` 都是普通 Python 包，
PyInstaller 会自动收集；若使用 onedir 模式，确认 `pyserial` 的
`serial.tools.list_ports` 被包含（默认会被收集）。
